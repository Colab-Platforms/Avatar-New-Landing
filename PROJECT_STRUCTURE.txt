Component Breakdown
===================

Layout Components:
- Navbar.tsx          : Sticky navigation, mobile menu, scroll effects
- Footer.tsx          : Multi-column layout, newsletter, social links

Hero & CTA:
- HeroSlider.tsx      : Auto-rotating slides, typewriter effect
- FinalCTA.tsx        : Final enrollment call-to-action

Content Sections:
- WhyChooseUs.tsx     : Features and benefits
- Programs.tsx        : Course offerings grid
- WhatYouLearn.tsx    : Curriculum details
- Benefits.tsx        : Learning outcomes
- Certifications.tsx  : Certificate showcase
- HowToEnroll.tsx     : Enrollment process

Interactive:
- DemoVideo.tsx       : Video player section
- Testimonials.tsx    : Infinite scroll carousel
- FAQ.tsx             : Accordion with Q&A

Utility:
- AnnouncementBar.tsx : Promotional banner
- StatsStrip.tsx      : Statistics display
- Logo.tsx            : Reusable SVG logo
